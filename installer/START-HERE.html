Hebrew in the right direction.

The installer prepares the Mac launcher and extension files. Finish these steps yourself in Chrome:

  1. Use the Chrome profile you use for Teams. Type chrome://extensions into Chrome’s address bar.
  2. Turn on Developer mode, then click Load unpacked.
  3. In the file picker press ⌘⇧G, paste the path below and click Open:
    ~/Library/Application Support/teams-web/extension
  4. Open teams-web in your home Applications folder. Sign in through Microsoft as usual.

Auto direction runs immediately. To show the Text shortcut beneath Teams’ left sidebar ellipsis, open the Teams RTL extension popup and enable its sidebar option. Auto keeps working with the shortcut hidden.

The extension can open a separate chat window during a call. The call stays in its original window.

This is a community beta, with manual extension installation and updates. It improves local composition; it cannot guarantee direction after sending or in recipients’ clients. Managed work computers may block developer extensions. The launcher is built locally and is not Apple notarized. The project does not disable macOS or Chrome security settings.
